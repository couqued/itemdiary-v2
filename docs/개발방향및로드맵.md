# 아이템 다이어리 — 개발 방향 및 로드맵

## 앱 정체성 (확정)

> **"내 소중한 물건들의 디지털 인벤토리"**

가전, 전자기기, 가구, 패션, 취미용품 등 **가치 있고 오래 쓰는 물건**의 구매 기록 + 생애주기 관리 앱.
단순한 지출 기록(가계부)이 아닌, **소유한 물건을 관리하고 나중에도 꺼내볼 수 있는 개인 자산 다이어리**.

---

## 방향성 검토 (현재도 같은 의견)

### 왜 '가계부' 방향은 피해야 하는가

이전 대화에서 나온 의견에 동의하며, 지금도 같은 입장입니다.

- **레드오션**: 토스, 뱅크샐러드, 카드사 앱이 카드 내역을 자동 연동. 사용자가 두루마리 휴지를 수동으로 기록할 이유가 없음
- **데이터 가치 없음**: 생활용품 구매 기록은 시간이 지나면 아무 의미 없음. 반면 맥북/다이슨/에르메스 구매 기록은 몇 년이 지나도 가치 있는 정보
- **수익화 어려움**: 가계부 앱은 광고 단가가 낮고, 수익 모델이 배너 광고뿐

### 초기 방향이 맞는 이유

"물건을 사면 나중에 A/S 기간이 언제까지인지, 어디서 샀는지, 얼마에 샀는지 다시 확인하고 싶다"는 니즈는 명확하고 차별화됨.
생활용품은 카테고리로 존재해도 되지만, **앱의 메시지와 UX는 가치 있는 물건에 집중**해야 함.

## 기능 검토 결과

### 채택할 기능 (우선순위 순)

#### 1순위 — 보증기간/교체주기 알림 ⭐⭐⭐
> **리텐션 핵심. 이 기능 하나만으로 앱을 안 지울 이유가 생김**

- items 테이블에 `warranty_date` (보증기간 만료일) 컬럼 추가
- ItemFormScreen에 보증기간 만료일 입력 필드 추가 (가전/전자기기 등록 시)
- 카테고리별 프리셋 제안: "가전제품은 보통 1년 A/S입니다. 설정할까요?"
- 만료 30일 전, 7일 전 푸시 알림 발송
- 소모품(필터, 생수 등) 교체 주기 알림도 동일 구조로 대응

#### 2순위 — 푸시 알림 인프라 (FCM + Supabase Edge Functions) ⭐⭐⭐
> **보증기간 알림의 전제 조건이며, 넛지 알림까지 함께 구현 가능**

- FCM(Firebase Cloud Messaging) 연동
- Supabase Edge Functions / Cron으로 매일 아침 조건 체크
- 알림 종류:
  - 보증기간 만료 임박
  - "N년 전 오늘 구매한 물건" 리마인더 (item_date 기반)
  - 위시리스트 장기 방치 아이템 ("담아두신 에어팟, 이번 달엔 살까요?")

#### 3순위 — URL 공유 → 상품 메타데이터 자동 파싱 ⭐⭐
> **이미 공유 인프라(ShareActivity) 있음. OG 파싱만 추가하면 됨**

- 현재: 쿠팡/네이버에서 공유하기 → 앱 실행 → URL 텍스트만 전달됨
- 개선: 받은 URL에서 OG 태그(og:title, og:image, og:description) 파싱 → ItemFormScreen에 상품명, 이미지, 링크 자동 입력
- 위시리스트 추가 UX를 극적으로 개선
- 기술: Node fetch + cheerio 또는 Supabase Edge Function으로 서버 사이드 파싱

#### 4순위 — 카테고리별 지출 차트 / 월간 리포트 ⭐⭐
> **ProfileScreen에 기본 통계 이미 있음. 차트로 확장**

- 카테고리별 지출 비율 파이/바 차트 (react-native-chart-kit 또는 victory-native)
- 월별 지출 추이 그래프
- "이번 달은 전자기기에 가장 많이 투자하셨군요!" 메시지
- 매월 1일 월간 리포트 팝업

#### 5순위 — 아이템 카드 이미지 공유 (바이럴) ⭐⭐
> **이미 공유하기 기능 있음. 예쁜 카드 이미지 생성만 추가**

- 아이템 상세화면에서 "공유" → 상품 이미지 + 이름 + 가격이 담긴 카드 이미지 생성
- 인스타그램, 카카오톡 등으로 공유 가능
- "나 이거 샀어" / "이거 사고 싶어" 자연스러운 바이럴
- 기술: react-native-view-shot으로 화면 캡처 후 공유

#### 6순위 — 아이템 카드 개선 (보증기간 배지) ⭐
- 만료 임박 아이템에 빨간 배지 표시
- 목록에서 한눈에 확인 가능

### 제외할 기능 (이유 포함)

| 기능 | 제외 이유 |
|---|---|
| **Notification Listener** (결제 알림 자동 파싱) | Play Store 정책상 매우 까다로운 민감 권한. 심사 통과 어려움. 개인정보 리스크 |
| **영수증 OCR** | Google Cloud Vision 비용 발생. "가계부" 느낌 강화. 앱 정체성과 어긋남 |
| **중고 시세 크롤링** | 당근/번개장터 공식 API 없음. 크롤링은 불안정하고 법적 회색지대 |
| **소셜 기능 (공동 위시리스트)** | 사용자 기반 먼저 확보 후 검토. 지금은 개발 대비 효과 낮음 |
| **홈 화면 위젯** | 개발 복잡도 높음 (네이티브 구현 필요). 핵심 기능 완성 후 검토 |

## 수익화 전략

### 단계별 수익 모델

**1단계 (현재 ~ 사용자 1만명)**: 무료 서비스로 사용자 확보
- 광고 없음. 순수 서비스 품질로 사용자 유입

**2단계 (사용자 확보 후)**: 제휴 마케팅
- 유저가 '소니 카메라' 등록 → "호환 렌즈 특가" 자연스럽게 노출
- 고가 제품 대상이라 광고 단가 높음 (생필품 광고 대비 압도적)

**3단계**: 프리미엄 구독 (월 1~2천원)
- 보증서/영수증 원본 무제한 고화질 보관
- 커스텀 알림 (교체 주기 등) 무제한
- 아이템 무제한 등록 (무료는 N개 제한)

**장기**: 중고 거래 연계
- 물건 정보(구매일, 상태, 영수증)를 당근/중고나라 양식으로 원클릭 복사
- 추후 매입 업체 연결 수수료

## 앱스토어 포지셔닝

**현재**: "뭐든지 기록하는 다이어리"
**목표**: "당신의 소중한 물건들을 관리하는 프라이빗 인벤토리"

**타겟 키워드**: 내 물건 관리, 가전 보증기간, 구매 기록, 아이템 다이어리, 소유물 관리

## UI/UX 방향 조정

- **카테고리 순서 조정**: 전자기기, 가전, 가구 최상단 → 식품, 생활용품은 뒤로
- **ItemFormScreen**: 보증기간 만료일 필드 추가 (선택 항목)
- **홈 화면**: 만료 임박 아이템 상단 배너 또는 배지 강조
