# v1.5 개발 계획 — 보증기간 기능 + LLM 자동 제안

## 목표 기능 요약

1. **상품 등록 시 LLM이 카테고리/보증기간/교체주기 자동 제안**
   - 상품명 입력 → LLM 호출 → 카테고리, 보증 만료일, 교체주기 자동 채움
   - 적용 대상: ItemFormScreen (직접 등록), ShareModalScreen (URL 공유)

2. **보증기간/교체주기 필드 추가**
   - 카테고리에 따라 관련 필드 자동 표시 (가전/전자기기 → 보증기간, 생활용품 → 교체주기)
   - 상세화면에서 남은 보증기간 표시
   - 목록에서 만료 임박 아이템 배지 표시

3. **LLM 호출은 Supabase Edge Function 경유** (API 키 보안)

## LLM 연동 구조

```
사용자 상품명 입력
    ↓
앱 → Supabase Edge Function (suggest-product-info)
    ↓
Edge Function → Gemini API (또는 Claude Haiku API)
    ↓
응답: { category_name, warranty_months, replacement_months, reason }
    ↓
앱에서 해당 필드 자동 입력 (사용자가 확인 후 수정 가능)
```

### LLM 프롬프트 예시
```
다음 상품명을 보고 JSON으로 답해줘.
상품명: "다이슨 V15 디텍트"

응답 형식:
{
  "category": "가전",           // 의류/신발/가방/가전/가구/잡화/전자기기/식품/도서/뷰티/생활용품/기타 중 하나
  "warranty_months": 24,        // 보증기간 (개월), 없으면 0
  "replacement_months": 12,     // 교체주기 (개월), 해당없으면 0
  "has_filter": true,           // 필터 등 소모품 여부
  "reason": "가전제품 기본 2년 보증"
}
```

## 파일별 작업 목록

### 1. Supabase Edge Function 생성 (신규)
**파일**: `supabase/functions/suggest-product-info/index.ts`

- Gemini API 또는 Claude Haiku API 호출
- 상품명 → { category, warranty_months, replacement_months } 반환
- CORS 헤더 포함

### 2. `src/lib/supabase.js` — Edge Function 호출 함수 추가
```js
export const suggestProductInfo = async (productName) => {
  const { data, error } = await supabase.functions.invoke('suggest-product-info', {
    body: { name: productName },
  });
  return error ? null : data;
};
```

### 3. `src/screens/items/ItemFormScreen.js` — 보증기간 필드 + LLM 제안
- 상품명 입력 후 포커스 벗어날 때 (onBlur) LLM 호출
- 카테고리 선택에 따라 보증기간 or 교체주기 필드 표시
  - 가전/전자기기/가구 → `warranty_date` DatePicker 표시
  - 생활용품 → `replacement_months` 선택 (1/3/6/12개월)
  - 의류/신발/가방/도서/식품/뷰티 → 해당 필드 숨김
- LLM 제안 시 "AI 제안: 보증 2년 / 필터 12개월 교체" 배너 표시 → 적용 / 무시 선택

**카테고리별 필드 표시 매핑**:
```js
const WARRANTY_CATEGORIES = ['가전', '전자기기', '가구']; // 보증기간 표시
const REPLACEMENT_CATEGORIES = ['생활용품'];               // 교체주기 표시
// 나머지는 표시 안 함 (추가 정보 섹션에만 선택 옵션으로)
```

### 4. `src/screens/items/ShareModalScreen.js` — LLM 정제 추가
- OG 파싱 완료 후 상품명을 LLM에 전달
- 상품명 클린업 (모델 코드, 광고 문구 제거) + 카테고리/보증기간 제안
- 현재 저장 시 category_id, warranty_date도 함께 저장

### 5. `src/screens/items/DetailScreen.js` — 보증기간 표시
- 보증 만료일이 있으면 표시:
  - D-30 이내: 빨간색 "보증 만료 임박 (D-N)"
  - 만료됨: 회색 "보증 만료"
  - 정상: 초록색 "보증 중 (N일 남음)"
- 교체주기 있으면: "다음 교체 예정: 2026-02-30"

### 6. `src/components/ItemCard.js` — 보증 임박 배지
- warranty_date가 30일 이내인 경우 카드에 작은 빨간 배지 표시

## 구현 순서 (Step by Step)

### Step 1. Supabase DB 컬럼 추가
Supabase 콘솔 → SQL Editor에서 위 ALTER TABLE 쿼리 실행

### Step 2. Gemini API 키 발급
Google AI Studio에서 API 키 발급 → `.env` 파일에 추가
```
GEMINI_API_KEY=발급받은키
```

### Step 3. Supabase Edge Function 생성
```bash
# Supabase CLI 설치 (안 되어 있으면)
npm install -g supabase

# 프로젝트 루트에서
supabase functions new suggest-product-info
```
`supabase/functions/suggest-product-info/index.ts` 작성 (Claude Code에 요청)

Edge Function에 환경변수 설정:
```bash
supabase secrets set GEMINI_API_KEY=발급받은키
```

### Step 4. Edge Function 배포
```bash
supabase functions deploy suggest-product-info
```

### Step 5. 앱 코드 수정
순서: supabase.js → ItemFormScreen → ShareModalScreen → DetailScreen → ItemCard

### Step 6. 테스트 빌드
```bash
cd android
UPLOAD_STORE_PASSWORD=<비밀번호> UPLOAD_KEY_PASSWORD=<비밀번호> ./gradlew assembleRelease
adb install android/app/build/outputs/apk/release/app-release.apk
```
